# Arsitektur dan Keputusan Teknis

Dokumen ini mencatat alasan di balik keputusan teknis yang disepakati. Gunakan format ADR berikut untuk keputusan baru. Jangan menghapus ADR lama; saat keputusan digantikan, ubah status ADR lama menjadi **Digantikan oleh ADR-XXX** dan tambahkan ADR pengganti.

## Status ADR

- **Diusulkan** — masih menunggu persetujuan.
- **Berlaku** — keputusan disetujui dan menjadi acuan.
- **Ditolak** — dipertimbangkan tetapi tidak dipilih; simpan alasan bila berguna.
- **Digantikan oleh ADR-XXX** — digantikan oleh keputusan yang lebih baru.
